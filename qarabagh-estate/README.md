# Qarabagh Estate — landing page

React 18 · Vite · Tailwind CSS 3 · Framer Motion 11 · Lucide React

## Run
    npm install
    npm run dev            # http://localhost:5173
    npm run build          # production build in /dist
    npm run build:single   # one self-contained dist/index.html

## Where things live
- `src/i18n.js` — all text in AZ / RU / EN, plus the CONTACT block (phone, email, WhatsApp, Instagram)
- `src/assets/` — photos (webp) and the logo/emblem cut from the Instagram profile picture
- `src/components/Pledge.jsx` — carousel; swap its items for real client reviews when you have them
- `src/components/Portfolio.jsx` — card photos; replace with photos of your own properties
